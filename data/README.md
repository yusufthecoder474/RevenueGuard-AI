# Dataset provenance

`synthetic-demo.csv` contains exactly 100 deterministic, artificial transaction rows generated by `scripts/generate-demo.py`. Its amounts, dates and product names are fixtures, not real sales, customer activity or measured business savings. Six rows are cancellations/returns and two positive-quantity rows have zero prices for explicit exclusion. The generator and its synthetic output are covered by the project MIT license.

`uci-demo.csv` contains 200 actual historical rows derived from **Online Retail**, Daqing Chen (2015), UCI Machine Learning Repository, https://doi.org/10.24432/C5BW33. Source page: https://archive.ics.uci.edu/dataset/352/online+retail. Dataset license: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

The UCI source describes transactions of a UK retailer during December 2010–December 2011. This small extract represents only the first eligible source rows; it is not a representative sample of the entire retailer. It does not necessarily contain all cancellation patterns. The synthetic fixtures cover returns and dirty inputs separately.

Changes to the original data: date values converted to ISO text; price values exported as decimal strings; CustomerID and Country removed; first eligible rows retained in source order; description conflicts, bad precision and malformed fields skipped with counts. See `uci-demo.provenance.json` for source/output hashes, exact row counts and selection policy. No customer identifiers are present in the distributed sample or LLM prompts.

The original 22.6 MB Excel file is deliberately excluded from the source bundle. To reproduce:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r scripts\requirements-data.txt
Invoke-WebRequest -Uri 'https://archive.ics.uci.edu/static/public/352/online%2Bretail.zip' -OutFile uci-retail.zip
Expand-Archive .\uci-retail.zip -DestinationPath .\uci-source
.\.venv\Scripts\python.exe scripts\prepare_uci.py '.\uci-source\Online Retail.xlsx' --output data\uci-demo.csv --limit 200
```

The converter uses pandas only for Excel I/O; Decimal parses and checks numeric text. It does not sum binary floats. Positive prices support up to four fractional digits. Runtime calculation classifies C invoices and negative quantities as return/cancellation lines, excludes zero/fractional/oversized quantities and invalid/nonpositive prices, and records exclusion reasons.

The dashboard calls `uci-demo.csv` a historical real sample and `synthetic-demo.csv` a synthetic demo. Those labels should be preserved in any presentation.
